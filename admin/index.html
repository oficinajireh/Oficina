Dólar del depósito

Se fija a mano. Se usa en ventas, cotizaciones y pagos, y para pasar a pesos los productos con precio en dólares (se recalculan solos cada vez que lo cambiás).

Documentos A4 (cotizaciones, boletas de entrega, estados de cuenta)

Salen en el encabezado y el pie de cada hoja, junto con el nombre, la dirección y los teléfonos de arriba.

Datos generales, ícono y SEO

Se usan al compartir el link del catálogo (WhatsApp, Facebook, X) y para buscadores como Google.

URL del catálogo online
Ese dato se edita en la pestaña Catálogo web → "Catálogo online (para los QR de precio)" — se usa tanto para los QR como para el SEO/redes, no hace falta repetirlo acá.
Encabezado del ticket (impresora térmica)
ℹ️ Estos datos se guardan en la hoja de cálculo (pestaña "CONFIGURACION") y se usan para armar el encabezado de todos los tickets impresos (ventas y cierres de caja). Como quedan en la planilla, se ven igual sin importar desde qué computadora o navegador entres al panel.
Dólar de referencia (tipo de cambio)

Qué cotización se trae sola como tipo de cambio en Ingreso de Productos (se usa el valor de venta del día). Igual lo podés editar en cada ingreso.

Instalador

Generá el código y los archivos para una nueva instalación
Paso 1 — Datos del cliente
La parte larga de la URL: docs.google.com/spreadsheets/d/ESTE_ID/edit
Paso 2 — Generar Code.gs

Descargá el archivo Code.gs con los datos del cliente ya insertados. Luego creá un proyecto en script.google.com, pegá el contenido y publicalo como Web App.

Instrucciones después de descargar:
1. Abrí script.google.com → Nuevo proyecto
2. Borrá el código de ejemplo y pegá el contenido del archivo descargado
3. Guardá (Ctrl+S), poné un nombre al proyecto
4. Click en Implementar → Nueva implementación
5. Tipo: Aplicación web · Ejecutar como: Yo · Acceso: Cualquier persona
6. Copiá la URL y pegala en el campo API URL de arriba
Paso 3 — Generar archivos del cliente

Generá el config.json con los datos del cliente, o el ZIP completo del catálogo web listo para subir al hosting.

Paso 4 — Verificar conexión y crear las hojas

Una vez publicado el Code.gs y pegada la API URL de arriba, tocá el botón — prueba que la conexión funcione y, de paso, crea en la planilla todas las hojas que el sistema necesita (si ya existían, no las toca).

Paso 5 — Activar el panel para este negocio

Con la conexión verificada, descargá el config.json del Paso 3 (con la API URL ya cargada) y colocalo en la raíz de esta instalación, al lado de la carpeta admin/. Al recargar esta página, el panel va a reconocer que ya está configurado y va a pedir usuario y contraseña por primera vez — usá admin / Jireh2026 (después la podés cambiar desde Configuración → Acceso al panel).
